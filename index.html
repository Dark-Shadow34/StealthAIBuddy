QUESTIONS & ANSWERS

Frequently Asked Questions

Does this overlay really not show on screen shares? +
Yes. Windows natively supports SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE) at the Desktop Window Manager (DWM) level. This completely excludes the HUD window from screen recording pipelines in Zoom, Microsoft Teams, Discord, Google Meet, and OBS Studio.
Is the Google Gemini API free to use? +
Yes. Google AI Studio provides a free tier for Gemini 2.0 Flash with up to 15 requests per minute and 1,000,000 tokens per minute. No credit card is required.
Are my API keys safe? +
Yes. All keys are encrypted at rest using Windows DPAPI (CryptProtectData). They can only be decrypted by your active Windows user account on your physical machine.
Do I need Python installed to run the application? +
No. The standalone executable (DesktopWindowHelper.exe) is completely self-contained with zero runtime dependencies. Just download and run.
